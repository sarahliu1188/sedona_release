# 释放 PWA

1. 在 GitHub 新建一个 public repository，例如 `release`.
2. 把本文件夹中的所有文件上传到 repository 根目录。
3. Repository → Settings → Pages。
4. Build and deployment 选择 `Deploy from a branch`。
5. Branch 选择 `main` 和 `/ (root)`，然后 Save。
6. 等待 GitHub Pages 发布完成后，打开它给出的 HTTPS 地址。
7. iPhone Safari：分享 → 添加到主屏幕。
   Android Chrome：菜单 → Add to Home screen / Install app。

发布后支持主屏幕启动和离线使用。
